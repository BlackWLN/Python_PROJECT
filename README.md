# Тренажёр для подготовки к ФИ и АиСД

Веб-приложение для подготовки к зачётам по фундаментальной информатике (ФИ) и алгоритмам и структурам данных (АиСД): банк вопросов с вариантами ответов, прохождение тестов по темам, личная статистика и рекомендации по слабым темам.

**Стек:** FastAPI + PostgreSQL (бэкенд), Streamlit (фронтенд), JWT-аутентификация.

## Об этом проекте кратко

Это учебный проект в рамках предмета "Разработка IT-проектов на языке Python". Отсюда несколько следствий:
- Для проверки кода учебного проекта большая часть файлов лежит тут в общем доступе. Как-то так:)
- В рамках ограниченного стека - только язык Python - была использована библиотека Streamlit для реализации фронтенда. На будущее можно превратить этот проект из MVP на Python в полноценное приложение. Предполагаемо - переписать на React.

## Возможности

- Регистрация и вход по email/паролю, пароли хранятся только в виде bcrypt-хэша, доступ к API — по JWT.
- Прохождение теста: вопросы выбираются по предмету и темам, показываются по одному в случайном порядке со случайным порядком ответов, без подсказок.
- Личная статистика: количество пройденных тестов, средний результат, место в общем рейтинге, слабые и сильные темы.
- Рекомендации тем для повторения на основе истории ответов (а для новых пользователей — по самым объёмным темам).
- Возможность добавить собственный вопрос в общий банк вопросов.

## Roadmap (пока не реализовано)

Часть функциональных требований из исходного ТЗ сознательно оставлена вне MVP, чтобы не размывать фокус — но архитектура (JWT-эндпоинты, отдельные таблицы) готова под их добавление:

- Вход через OAuth (Google/GitHub и т.п.).
- Ограничение времени на отдельный вопрос (сейчас — только общий таймер на тест).
- Телеграм-бот для прохождения тестов и геймификации.
- Оценка вопросов/тестов пользователями, предложение правок к существующим вопросам.
- Система ачивок и уровней.

## Архитектура

```
frontend/  Streamlit-приложение (UI), обращается к API по HTTP + JWT в заголовке Authorization
   ├─ home_page.py        точка входа, дашборд со статистикой
   └─ pages/
        1_page_sign_in.py, 2_page_sign_up.py   — вход/регистрация
        3_page_greeting.py                      — публичный лендинг
        4_page_select_test.py                   — выбор предмета/тем
        5_page_quiz.py                          — прохождение теста
        6_page_quiz_final.py                    — результаты + рекомендации
        7_page_create_test.py                   — добавление вопроса

app/       FastAPI-бэкенд
   ├─ api/v1/endpoints/    auth.py (register/login), quiz.py (questions/answers/stats)
   ├─ services/            бизнес-логика + SQL-запросы (psycopg2, без ORM)
   ├─ schemas/             pydantic-модели запросов/ответов
   └─ core/config.py       настройки из переменных окружения

createdb.sql, load_data (2).sql   схема БД и тестовые данные (Postgres)
```
